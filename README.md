PetCare 🐾Cuidado, carinho e praticidade para o seu pet!Uma plataforma web moderna desenvolvida para facilitar o acesso a produtos, agendamento de serviços veterinários e a gestão completa de petshops.📋 1. Sobre o projetoO PetCare é uma aplicação web desenvolvida com o objetivo de proporcionar praticidade e eficiência no atendimento a tutores de animais de estimação e na administração de petshops.A plataforma oferece uma interface acolhedora e intuitiva, unindo o e-commerce de produtos pet ao agendamento de serviços de cuidados (como banho, tosa e consultas), além de incluir um Painel Administrativo em tempo real integrado com base de dados para a gestão do negócio.🎯 2. Objetivos do projetoDesenvolver uma plataforma digital completa voltada ao universo pet.Integrar a aplicação a uma base de dados relacional (Supabase) para persistência de produtos, serviços e agendamentos.Implementar um fluxo de e-commerce funcional (catálogo, seletor de quantidade, carrinho e modal de entrega).Disponibilizar uma área administrativa exclusiva para o dono do petshop gerir a sua loja.Aplicar conceitos avançados de desenvolvimento front-end com React e estilização responsiva.✨ 3. Funcionalidades principaisPágina Inicial (Home): Apresentação visual da marca, destaques e acessos rápidos.Loja Online (Produtos): Catálogo de produtos com preços, descrições, filtro e seletor de quantidade.Carrinho e Checkout: Gestão de itens selecionados e preenchimento de morada de entrega.Serviços e Agendamentos: Escolha de cuidados para o pet com marcação de data, hora e modalidade.Painel Administrativo: Área exclusiva para o administrador visualizar indicadores e gerir o petshop de forma dinâmica.🛠️ 4. Tecnologias utilizadasTecnologiaFinalidadeReactConstrução de componentes reutilizáveis e gestão de estados da interface.ViteEmpacotador e ambiente de desenvolvimento rápido.SupabaseBase de dados em nuvem e backend as a service para produtos, serviços e agendamentos.JavaScript (ES6+)Lógica de programação e interatividade da aplicação.CSS3Estilização personalizada com design responsivo e tons terrosos.Git & GitHubControlo de versão e colaboração em equipa.🎨 5. Identidade visualA identidade visual do PetCare foi planeada para transmitir proximidade, confiança e bem-estar animal, utilizando uma paleta de cores terrosas e acolhedoras:Marrom Escuro (#4B2D27): Usado em cabeçalhos, menus e textos principais.Bege Claro (#F6F0E8): Cor de fundo geral da aplicação.Caramelo / Terracota (#BD855D): Destaques, botões e elementos interativos.📚 6. Considerações finaisO desenvolvimento do PetCare representa a consolidação prática dos conhecimentos adquiridos no curso de Análise e Desenvolvimento de Sistemas (ADS).
